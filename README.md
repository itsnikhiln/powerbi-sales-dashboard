# 📊 Sales Dashboard — Power BI

## 📌 Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales performance, profit, orders, products, categories, and regional performance.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## 📊 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top Performing Products
- Interactive Filters and Slicers
